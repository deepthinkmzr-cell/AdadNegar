# عددنگار — عدد به حروف — پروژهٔ اندروید

نسخهٔ اول یک برنامهٔ ساده و آفلاین برای تبدیل عدد صحیح به حروف در سه بخش است:

- دری افغانستان
- فارسی
- English

## امکانات

- تبدیل فوری هنگام تایپ
- پشتیبانی از ارقام انگلیسی، فارسی و عربی؛ مثل `150000`، `۱۵۰۰۰۰` و `١٥٠٠٠٠`
- پذیرش جداکننده‌های معمول مثل ویرگول و فاصله
- کپی جداگانهٔ نتیجهٔ هر زبان
- پردازش گروه‌های سه‌رقمی به‌جای تبدیل کل عدد به نوع عددی محدود؛ در نتیجه با عددهای بسیار بزرگ هم کار می‌کند
- عملکرد آفلاین؛ برنامه مجوز اینترنت نمی‌خواهد

## استفادهٔ فوری بدون نصب Android Studio

فایل `index.html` را از ZIP بیرون کن و با مرورگر باز کن. تمام منطق تبدیل در همان فایل قرار دارد و برای آزمایش اولیه به اینترنت نیاز نیست.

## ساخت اپلیکیشن اندروید (APK)

1. Android Studio را نصب کن و SDK مربوط به Android 35 را از SDK Manager نصب کن.
2. در Android Studio گزینهٔ **Open** را بزن و پوشهٔ اصلی `AdadBeHorof` را انتخاب کن.
3. اجازه بده Gradle و پلاگین‌های پروژه دریافت و Sync شوند. تنظیم پروژه از Android Gradle Plugin `8.7.3`، Kotlin `2.0.21` و Gradle `8.9` استفاده می‌کند.
4. برای ساخت APK در ویندوز، فایل `build-apk-windows.bat` را اجرا کن؛ در Linux/macOS فایل `build-apk-linux-mac.sh` را اجرا کن. این اسکریپت‌ها در صورت نیاز Gradle 8.9 را دانلود می‌کنند. باید SDK و اتصال اینترنت برای دریافت ابزارهای ساخت فراهم باشد. همچنین می‌توانی در Android Studio گوشی را با USB وصل کنی و **Run** را بزنی.
5. مسیر APK آزمایشی پس از ساخت: `app/build/outputs/apk/debug/app-debug.apk`

این فایل ZIP شامل کد منبع پروژه است؛ APK از پیش‌ساخته داخل آن نیست، چون محیط ساخت در زمان تهیهٔ فایل Android SDK/Gradle نصب‌شده نداشت.

## دربارهٔ نگارش اعداد

سه رقم سه رقم خوانده می‌شود. نگارش فارسی و دری برای بعضی صدگان تفاوت دارد؛ مثلاً در دری `یک‌صد` و در فارسی `صد` استفاده شده است. در انگلیسی از الگوی رایج آمریکایی بدون `and` استفاده شده است. نام مقیاس‌های رایج تا `vigintillion`/«ویجینتیلیون» تعریف شده؛ برای مرتبه‌های بالاتر که نام رایج و تثبیت‌شده‌ای در فهرست برنامه ندارند، شمارهٔ مرتبه نمایش داده می‌شود.

این نسخه برای **عددهای صحیح نامنفی** ساخته شده است؛ اعشار و عدد منفی فعلاً پشتیبانی نمی‌شوند.


## نام و آیکن برنامه
- نامی که روی صفحهٔ گوشی نمایش داده می‌شود: **عددنگار**
- آیکن لانچر سفارشی در پوشه‌های `app/src/main/res/mipmap-*` قرار دارد.

## دربارهٔ فایل APK
این بسته، پروژهٔ منبع اندروید است و APK کامپایل‌شده داخل آن نیست. برای ساخت APK آزمایشی، Android Studio/Android SDK 35 و دسترسی دریافت Gradle و افزونه‌های اندروید لازم است؛ سپس `build-apk-windows.bat` را در ویندوز اجرا کن. خروجی در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.
